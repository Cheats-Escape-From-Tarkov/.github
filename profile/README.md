## ✨ Key Features

**Loot Filtering**
- 🎒 **Loot ESP** — Highlights items by category and value threshold.
- 📦 **Container Filter** — Restricts highlights to selected container types.
- 💰 **Item Value Overlay** — Shows flea-market value next to each drop.

**Raid Awareness**
- 🗺️ **Extraction Map** — Draws extraction points and route hints.
- 👁️ **Player ESP** — Highlights other players with distance.
- 🐻 **Boss ESP** — Marks boss and guard spawns by map.

**Configuration**
- 🎛️ **Profiles** — Save loot filters per map and per quest.
- ⌨️ **Hotkey Panel** — Rebind every module from one screen.
